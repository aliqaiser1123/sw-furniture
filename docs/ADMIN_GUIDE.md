# Admin Guide

Welcome to the Shesham Wood Furniture Admin Dashboard.

## Roles
- **CUSTOMER**: Can view products, place orders, and manage their profile.
- **ADMIN**: Has full access to the business dashboard, CMS, and settings.

## Modules

### 1. Catalog (Products, Categories, Collections)
- **Products**: Add new furniture items. Ensure you upload high-quality WebP or JPEG images. Assign a unique SKU.
- **Stock Management**: The system automatically deducts stock upon order placement. You will see "Low Stock" alerts on the analytics dashboard when inventory drops below 10.
- **Categories**: Keep categories broad (e.g., "Living Room").
- **Collections**: Use collections for marketing groups (e.g., "Summer Sale 2026").

### 2. Orders & Customers
- **Orders**: Track the lifecycle of an order (`PENDING` -> `PROCESSING` -> `SHIPPED` -> `DELIVERED`).
- If an order is canceled, the stock is NOT automatically refunded yet in V1.0. You must manually adjust the stock in the Products tab.
- **Customers**: View customer order history and lifetime value.

### 3. CMS (Content Management)
- **Banners**: Manage the rotating hero images on the homepage.
- **Static Pages**: Edit the Privacy Policy, Terms, and landing pages.
- **FAQs**: Manage the accordion questions on the support page.

### 4. Settings
- **AI Settings**: Swap between OpenAI, Anthropic, and Gemini. You can adjust the "Temperature" (creativity) of the AI assistant here.
- **Analytics**: Configure GA4 and Meta Pixel tracking IDs. No code changes are required.
