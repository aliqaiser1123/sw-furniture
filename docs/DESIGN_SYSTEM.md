Version: 1.0

# Purpose

This document defines the complete visual identity and UI design language for the Shesham Wood Furniture platform.

Every page, component, and future feature must follow these guidelines.

---

# Design Philosophy

The website should feel:

- Premium
- Elegant
- Warm
- Minimal
- Luxury
- Modern
- Fast
- Trustworthy

Avoid:

- Cluttered layouts
- Bright flashy colors
- Too many animations
- Cheap marketplace appearance
- Heavy shadows
- Inconsistent spacing
